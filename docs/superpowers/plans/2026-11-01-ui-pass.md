# UI Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Satu layar combat terpadu untuk DM dan player (map + urutan turn + hotbar aksi + panel Resolusi/Dadu/Rules), status tim yang aman, halaman lain tanpa scroll panjang, serta identitas Campfire Tales dengan ikon fantasy.

**Architecture:** Server hanya mengubah proyeksi combat/scene untuk status tim dan tanda kasar monster. Web memecah `CombatTracker` menjadi `CombatScreen` (layout) + `TurnOrder` + `ActionBar` (memakai ulang logika `ActionWizard` lewat hook) + `SidePanel`, memakai `BattleMap` yang ada. Halaman lain memakai komponen `Tabs` dan `Pager` bersama. Ikon diekstrak sekali dari `@iconify-json/game-icons` ke modul TS yang di-commit.

**Tech Stack:** React/Vite + react-i18next, NestJS + node:sqlite, Vitest, Playwright 1.64.1, `@fontsource/cinzel`, `@fontsource/crimson-pro`, `@iconify-json/game-icons` (dev, ekstraksi saja).

**Spec:** `docs/superpowers/specs/2026-11-01-ui-pass-design.md` (spec utama `docs/superpowers/specs/2026-10-30-dnd-platform-design.md` tetap otoritas aturan/akses).

## Global Constraints

- Nama produk: `Campfire Tales` (EN dan ID sama). Tidak ada "D&D", "DND", "Dungeons & Dragons", atau aset/nama Baldur's Gate 3 di UI, aset, atau dokumen produk.
- Tema perkamen yang ada dipertahankan: token di `:root` `apps/web/src/app/styles.css` tidak diganti nilainya; mode gelap otomatis tetap.
- Semua font/ikon disajikan dari host; tidak ada URL CDN di build.
- Atribusi: game-icons.net (CC BY 3.0, penulis per ikon) dan SRD 5.2.1 (CC BY 4.0) tampil di halaman `Credits`.
- Breakpoint: `wide` ≥1200 px (tiga kolom + hotbar), `medium` 768–1199 px (map + hotbar, urutan turn & panel sebagai laci), `narrow` <768 px (tab bawah: Map, Karakter, Aksi, Turn, Lainnya).
- Pagination 20 item per halaman.
- Player tidak pernah menerima angka HP/AC/save monster, makhluk tersembunyi, slot/inventory/catatan karakter lain. Penyaringan hanya di server.
- Tombol command nonaktif saat tidak `connected`; tidak ada mutasi lokal sebelum ack.
- Semua teks baru EN/ID; `npm run locales:audit` lulus. Teks tidak terpotong/overflow di 360 px dan 1280 px untuk EN dan ID.
- Ikon dipetakan per jenis (school, tipe damage, kategori senjata, heal/buff/gerak/reaksi/fitur/aksi monster), bukan per spell.

## Review Focus

1. Combat tanpa scene (sceneId null) — layar tetap utuh: area map menampilkan pesan kosong, target dipilih dari urutan turn. Test di Task 3.
2. Makhluk disembunyikan DM saat sedang dipilih sebagai target player — pilihan target terhapus pada snapshot berikutnya, tidak dikirim di `combat.act`. Test di Task 4.
3. Player membuka hotbar — hanya combatant miliknya yang bisa dipilih sebagai aktor; tidak ada ubin untuk monster/karakter lain. Test di Task 4.
4. Nama/label sangat panjang (60 karakter, ID) di baris turn dan ubin hotbar — terpotong dengan elipsis + `title`, tanpa overflow horizontal. Test di Task 7 (E2E).
5. Offline di tengah aksi hotbar — ubin dan tombol konfirmasi nonaktif; ack hilang menampilkan "Ulangi aksi yang sama" dengan envelope yang sama. Test di Task 4.
